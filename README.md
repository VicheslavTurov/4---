📝 Текстовый редактор / Индексатор файлов
Консольное приложение на C# с двумя режимами: простой редактор с отменой действий и поиск ключевых слов в .txt файлах (рекурсивно по папкам).

🚀 Возможности
Редактор

Просмотр и добавление текста

Undo через стек состояний (Memento)

Сохранение/загрузка в XML (data.xml)

Индексатор

Рекурсивный обход указанной директории

Поиск регистронезависимых ключевых слов в .txt файлах

Вывод статистики и путей найденных файлов

⚙️ Требования
.NET Framework / .NET Core / .NET 5+

Любая ОС с консолью

🔧 Быстрый старт
bash
# Компиляция (например, csc)
csc Program.cs

# Запуск
Program.exe
📋 Использование
Главное меню:

text
1. Редактор
2. Индексатор
0. Выход
Редактор: добавляйте текст, отменяйте изменения, сохраняйте/загружайте XML.
Индексатор: введите путь к папке и ключевые слова через запятую, получите результат.

📁 Структура кода
TextDocument – данные документа + сериализация

EditorMemento – снимок состояния

ConsoleEditor – логика редактора и история

FileSearchIndexer – поиск файлов и индексация
